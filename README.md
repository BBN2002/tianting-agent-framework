# 天庭智能体框架（Tianting Agent Framework）

一个**纯前端、单文件 HTML** 的趣味演示页：用「天庭仙班」比喻**多智能体协作**——你写下凡间任务（祈愿），页面里众仙「议政」，最后产出**玉帝敕令**（结构化结论）和可选的**下凡执行清单**。

> **定位**：灵感工具、工作坊破冰、教学类比（多角色分工 / 编排 / 记忆 / 并行），**不是**生产级 Agent 运行时。真能力取决于你是否接入大模型 API 以及模型本身。

---

## 用来做什么

| 场景 | 说明 |
|------|------|
| **演示与讲故事** | 把「编排、意图、执行、重试、记忆、优化、并行、长上下文、流水线」映射到玉帝、太白金星、二郎神等角色，方便向非技术同事解释多 Agent 分工。 |
| **单机脑暴** | 在「祈愿池」里写需求或问题；不开 API 时走**殿内模拟**议政与模板敕令；开 API 时由模型生成**可落地的仙议 + 敕令 + 执行步骤**（见下文）。 |
| **同机多窗协作** | 使用浏览器 `BroadcastChannel`：同一浏览器打开多个标签页加载本仓库页面，一窗发起「焚香合议」，其他窗可同步看到同一愿文触发的流程（各窗是否走真模型、是否填 Key 独立配置）。 |

---

## 功能概要

- **天庭编制**：点选仙神，查看其对应的工程隐喻（Orchestrator / Intent / Agent 等）。
- **凌霄议政**：焚香合议后，模拟或真实生成多条「仙议」记录。
- **玉帝敕令**：诏书体 + 可选「下凡执行清单」；支持导出 JSON。
- **天运赐福面板**：基于愿文哈希的**娱乐向**进度条与指数（非科学评测）。
- **可选真模型**：若你自有 **OpenAI 兼容**网关（如常见 One-API / New API 形态），可在页面内填写 **Base URL、API Key、模型 ID**；请求发往 `{BaseURL}/v1/chat/completions`，**密钥仅保存在本机浏览器**（可选勾选写入 `localStorage`，勿在公共电脑使用）。

## 本地使用

1. 克隆本仓库。
2. 用浏览器直接打开根目录下的 **`tianting-agent-framework.html`**（或部署后用 `index.html` 自动跳转）。
3. 不勾选「敕令与议政由真模型生成」时，无需任何密钥即可体验完整 UI 与模拟内容。

---

## 接入大模型 API（可选）

1. 在页面右侧 **「天曹 · 文昌阁 API」** 填写：
   - **网关 Base URL**：形如 `https://你的网关域名`，**不要**在末尾写 `/v1/chat/completions`（程序会自动拼接 `/v1/chat/completions`）。若误填了以 `/v1` 结尾的地址，会尝试自动剥除一层 `/v1`。
   - **API Key**：由你自己的服务商生成；**切勿**把 Key 写进代码、截图发公开区或提交到 Git。
   - **模型 ID**：填写该网关中已开通、可用的模型名。
2. 勾选 **「敕令与议政由真模型生成」**，并点击 **「保存天曹设置」**。
3. 若浏览器控制台出现 **CORS 跨域**错误，说明网关未允许当前页面来源，需在网关侧配置 CORS、或将本页托管到网关允许的域名下、或使用本地反向代理；这不是本仓库能单独解决的浏览器安全策略问题。

## 安全与隐私（请务必阅读）

- **本仓库不包含、也不应包含任何 API Key。** 若你曾在聊天或 issue 中泄露过 Key，请立即在服务商控制台**轮换或作废**。
- Key 只应通过页面表单输入；**不要**把含 Key 的截图、`.env`、fork 后的个人提交推送到公开仓库。
- 勾选「将密钥写入本机」时，Key 存于浏览器 `localStorage`，**换电脑或清除站点数据即需重新填写**。

## GitHub Pages 部署

将仓库推送到 GitHub 后，在仓库 **Settings → Pages** 中选择分支与根目录（`/ (root)`），站点根路径会提供 **`index.html`**，自动跳转到主页面 `tianting-agent-framework.html`。
